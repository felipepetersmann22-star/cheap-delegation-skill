# Cheap Delegation

Scope delegated work, write concise briefs and avoid unnecessary duplicated work.

## Install

Clone this repository into your agent's skills directory, keeping `SKILL.md` and its supporting files together. For Codex:

```sh
git clone https://github.com/felipepetersmann22-star/cheap-delegation-skill.git ~/.codex/skills/cheap-delegation
```

Restart or refresh skill discovery if needed. Other agents may use a different skills directory.

## Use

Use when planning subagent work or following up on delegated tasks. The included worker brief is in `assets/worker-brief.md`. Preserve required independent reviews and quality checks.
