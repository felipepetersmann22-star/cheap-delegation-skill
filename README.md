# Cheap Delegation

Delegate work without losing the quality of the result.

Use for substantial independent work, specialist contributions, or a required independent review. The skill scopes workers, assigns ownership and integrates their output. It does not spawn workers or authorize side effects by itself.

## Install

Clone the repository into your agent's skills directory, keeping `SKILL.md` and its supporting files together. For Codex:

```sh
git clone https://github.com/felipepetersmann22-star/cheap-delegation-skill.git ~/.codex/skills/cheap-delegation
```

Refresh skill discovery if your agent requires it. Other agents may use a different directory. Review any skill before installing it.

## Example

For a frontend and backend task, assign separate file ownership and keep a required reviewer independent. For a single file lookup, do the lookup directly.

[Worker brief](assets/worker-brief.md) is an optional starting point.

## Limits

This is a set of instructions, not a service. Results depend on the agent, available tools and task context; it cannot prove an action succeeded without checking the actual result.
